# 🇬🇧 English Easy — приложение для изучения английского

Простое веб-приложение для изучения английского языка. Работает без установки и без интернета.

## Как запустить
Открой файл `index.html` в любом браузере (Chrome, Firefox, Edge, Safari) — на компьютере или телефоне.

## Что умеет
- **🔤 Азбука — начни здесь**: 26 букв с названием, звуком, словом и картинкой; фоника (sh, ch, th, ee, oo, немая e…); игра «Первая буква» и все игры на словах азбуки
- **📚 Чтение книги**: 22 рассказа — путь от A1 до C2 маленькими шагами (A1: 7, A2: 4, B1: 4, B2: 3, C1: 2, C2: 2). Начинается с самых простых детских историй («Hello, I'm Sam»). Следующий рассказ открывается после предыдущего
  - **🗺 карта пути** на главной показывает, сколько пройдено на каждом уровне, и кнопку «Продолжить»
  - в конце — **🏁 финиш и сертификат** с именем, который можно распечатать
  - нажми на любое слово — увидишь перевод, начальную форму и подсказку по грамматике
  - кнопка ↔ переводит предложение целиком
  - **🔊 озвучка**: ▶ у каждого предложения, «Слушать весь текст» с подсветкой текущего предложения, у каждого слова — «Послушать» и «🐢 Медленно»
  - к каждому рассказу есть **правило** (грамматика + правило чтения) и упражнения на него
  - слова, которые ты переводил, попадают в **«⭐ Мои слова»**, и после текста их можно выучить в играх
- **⚡ Игра «На скорость»**: 60 секунд, 3 жизни, комбо за серию правильных ответов, рекорды
- **📖 8 тем словаря** (80 слов): основы, семья, еда, животные, дом, глаголы, цвета и числа, путешествия
- **🃏 Карточки**: слово, перевод и пример предложения
- **✅ Тест**: выбор перевода в обе стороны (англ → рус и рус → англ)
- **⌨️ Написание**: пишешь слово по-английски, есть подсказки
- **🔗 Пары**: соедини слово с переводом
- **🎧 На слух**: слушаешь слово и выбираешь, какое прозвучало
- **🔊 Озвучка** английских слов голосом устройства; можно включить медленную скорость в настройках. Если английского голоса нет, приложение подскажет, как его установить
- **✏️ Грамматика**: to be, артикли, Present Simple, Present Continuous — теория и упражнения
- **⭐ Прогресс**: очки опыта, выученные слова, серия дней подряд, повторение слов с ошибками

Прогресс сохраняется в браузере (localStorage).

## Как добавить рассказ
Открой `stories.js` и добавь объект в массив `STORIES`: текст по предложениям с переводом, правило, упражнения и словарь слов, которых нет в `COMMON_DICT`.

## Как добавить слова
Открой `data.js` и добавь строку в нужную тему в формате:
```js
["word", "перевод", "Example sentence."],
```

## Файлы
- `index.html` — страница
- `style.css` — оформление (есть тёмная тема)
- `app.js` — логика приложения
- `data.js` — слова и уроки грамматики
- `stories.js` — рассказы для чтения, правила и словарь
- `alphabet.js` — азбука и фоника

# ✖️ Таблица умножения — `multiplication/index.html`

Отдельное приложение-тренажёр. Открой `multiplication/index.html` в браузере.

Порядок обучения:
1. Учим на 2 → тренажёр на 2
2. Учим на 3 → тренажёр на 3 → повторяем на 2 и 3 → тренажёр на 2 и 3
3. Учим на 4 → тренажёр на 4 → повторяем на 2, 3 и 4 → тренажёр на 2, 3 и 4
4. …и так до 9, в конце — большой экзамен по всем таблицам

Следующий шаг открывается после предыдущего.

Игровая форма: каждая таблица — остров со своим другом (🐰 2, 🐻 3, 🦊 4, 🐸 5, 🐼 6, 🦁 7, 🐙 8, 🐉 9, 👑 финал). Пройди остров — друг попадёт в коллекцию. В тренажёре герой бежит к подарку, есть серии 🔥, конфетти и звуки (выключаются кнопкой 🔊).

Подсказки на перестановку: в таблице отмечено, какие примеры «🔄 уже знаешь» (например, 3 × 2 = 2 × 3 из таблицы на 2), сколько новых, есть «Волшебная перестановка» с поворотом точек. В тренажёре кнопка 💡 и подсказка после ошибки: «Поменяй числа местами! 8 × 3 = 3 × 8 — это таблица на 3». В тренажёре можно ошибиться не больше 3 раз (в смешанном — 4), иначе нужно пройти ещё раз. Ошибочный пример нужно решить заново, потом он вернётся ещё раз через пару вопросов (с переставленными числами), а в следующих тренажёрах будет попадаться чаще, пока ребёнок не решит его без ошибки. В таблице такие примеры отмечены «❗ была ошибка». За тренажёры даются звёзды, прогресс сохраняется в браузере.
